# Deprecated

Orbis Companies is deprecated. This repository is no longer maintained, and no new features, bug fixes, or releases are planned.

## Successor

The [Orbis Organizations](https://github.com/pronamic/wp-orbis-organizations) plugin is the successor of this plugin. Please use Orbis Organizations for new and existing Orbis environments.

## For current users

1. Install and activate the [Orbis Organizations](https://github.com/pronamic/wp-orbis-organizations) plugin.
2. Move your company data to organizations.
3. Deactivate and delete the Orbis Companies plugin.

Existing code and documentation are retained as a historical reference only.
